# Roadmap

This roadmap is informational, subject to change, and **does not promise release dates**.

## Available now

- [x] Public GitHub repository with v0.1.3 source code.
- [x] Downloadable **v0.1.3 stable** ZIP and step-by-step [installation instructions](INSTALL.md).
- [x] Downloadable **v0.1.4 preview** ZIP with English, Russian, and Czech translations, browser-language detection and language switching.
- [x] Four-state toolbar indicator and user-selected service components.

## Near-term development

- [ ] Review and merge the v0.1.4 localization source code via a GitHub Pull Request.
- [ ] Test unpacked installation and updates in a regular desktop Chrome session.
- [ ] Review translations and document how community members can propose improvements.
- [ ] Decide on an appropriate source-code license (not selected yet).

## Planned Chrome Web Store publication

**Status: planned — not published, no launch date.**

- [ ] Finalize the version intended for the first store submission.
- [ ] Confirm functionality and permissions in Chrome.
- [ ] Check branding, privacy policy and store-policy compliance.
- [ ] Prepare the Chrome Web Store description, screenshots and promotional graphics.

- [ ] Submit the distribution ZIP for review and address any review feedback.

Until then, use the GitHub downloads and the **Load unpacked** process in [INSTALL.md](INSTALL.md).

## Distribution and community
