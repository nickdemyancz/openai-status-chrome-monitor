# Changelog

## [0.1.3] — 2026-10-20

Initial public-source version prepared for GitHub.

- Independent three-segment triangular brand icon.
- Matching green, yellow, red, and gray toolbar icons for service health.
- Service status popup with user-selected components.
- Automatic refresh every 5, 30, or 60 minutes, plus manual-only mode.
- Dynamic component catalog, local settings, and basic stale-data handling.
- Chrome Manifest V3, without external dependencies or analytics.

> This is a preview release. Chrome Web Store publication is not yet claimed.
